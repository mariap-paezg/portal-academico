¿Qué es este portal?

Espacio de apoyo del curso de Programación Web.

Importante: el proyecto del curso se construye por etapas.

El curso usa una API REST y no plantillas del servidor.

Lo más importante de esta fase: HTML5 semántico.

La web semántica mejora la comprensión del contenido.

Fuente: Guía definitiva de HTML5 semántico

Última actualización: 30 de septiembre de 2026

Fases del curso

Fase 1 — Frontend moderno

HTML5 semántico, CSS3, Bootstrap y JavaScript ES6+.

Fase 2 — Control de versiones

Git, ramas, GitHub y Pull Requests.

Fase 3 — Metodologias Agiles

Scrum, Kanban y metodologías ágiles.

Fase 4 — Desarollo Backend por Sprints

Desarrollo de aplicaciones backend utilizando metodología de sprints.
